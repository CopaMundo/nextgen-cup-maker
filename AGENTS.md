# Architecture rules

- Keep rounds-draw pot assignments per group in a phase-scoped browser draft and include them in the final draw report; phase-wide pot tables cannot replace group-specific assignments, and applying clears the draft.
- Style both live-draw dialogs with the shared draw-dialog-theme, draw-choice, draw-panel, and draw-table roles; shared tokens prevent the group and rounds workflows from drifting visually.
- Render both live draws inside one secured modal wizard that blocks outside-click and Escape dismissal; phase drafts preserve refresh recovery.
- Use equal-size pot choices and the shared fixed PotTeamSlots selector in both draw views; a bounded slot cannot overfill a pot and keeps assignment behavior consistent.
- Share one timestamp-driven 16:9 draw stage between admin and projector; inject organizer-only controls and publish phase timing. Complete each received team reveal with a bounded monotonic playback clock and queue newer team events before returning to published timing; latency or suspended rendering must not skip flight/split, and opponent-only updates never restart it. Consume projector change payloads directly and discard older reads to avoid losing intermediate draws.
- Bake replacement studio frames into the shared 16:9 artwork at the existing 29–71% horizontal and 39–49% vertical reveal bounds; this preserves the 50%/44% ball origin and measured transfer landings without separate decorative overlays.
- Publish tournament title, language, theme, speed and flag-backdrop visibility in shared draw presentation metadata; use measured identical periods for the straight LED repeat loop and share heading, metallic brand and flag rendering so director/projector geometry stays identical.
- Share phase-scoped show options across both draw preparation and director settings; publish only presentation metadata during setup and revealed identities during the show so a public QR/watch URL never receives organizer controls or hidden fixtures.
- Fullscreen the director stage container rather than the document; mount its popovers, selectors and shared scope-confirmation dialogs within that container so controls remain usable in browser fullscreen.
- Auto-trim transparent logo margins in the shared draw stage at render time and cache the result; source uploads stay unchanged while projector and director receive identical optical alignment.
- Publish rounds through the shared draw picture using only revealed opponent identities and timestamped reveals; the precomputed schedule stays in the phase draft so both stages synchronize without disclosing upcoming opponents.
- Keep fixture show order separate from scheduled rounds, anchoring previously revealed encounters using earlier drawn teams before sorting open rows by pot; gate fixture and roster-badge identities by shared reveal timestamps so both stages reveal together without row jumps or schedule changes.
- Keep the rounds reveal start gate in the phase draft and reset it on each team draw; director controls start sequential or manual reveals explicitly without changing the precomputed schedule or published identity timing.
- Publish a roster completion timestamp only when all of a drawn team's fixtures are revealed; the shared stage gates its gold state and entire badge set together, independently of alphabetical display order and measured overflow scrolling.
- Keep overflowing rounds rosters scrollbar-free with a measured continuous loop, and never disable draw-stage animations for OS reduced-motion settings; the draw is a projected show whose ball flight, split and roster loop must look identical on every machine.
- Share live-show round availability between phase entry choices and rounds preparation, including recovered drafts; presentation limits must never block group draws or tournament schedule generation.
- Calculate group-wing geometry and the five studio profiles centrally from actual wing groups and internal slot rows, expose them on the shared stage, and observe stage and transfer-slot resize; director and projector must share readable content-hugging layouts and exact landings after rescaling. Expose each wing's column count and actual internal slot-row occupancy so its trailing unpaired card retains one-column width and CSS can bound breathing gaps without stretching cards.
- Calculate balanced overview pages centrally with timestamp-aligned switching on the shared stage and measure target slot dimensions and identity sizes for transfer morphs; projector pagination and slot arrivals must match the director.
- Filter a clipped duplicate of the shared studio background for bowl recoloring rather than using backdrop-filter; this guarantees visible theme changes without filtering balls or the pedestal.
- Render draw balls in one transparent R3F canvas using Cannon sphere/concave-bowl contacts; drive flight/split from shared bounded playback time and preserve full-stage orthographic coordinates so both stages align. Gate overview dimming by completed reveal playback, not bowl removal.
