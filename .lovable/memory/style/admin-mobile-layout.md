---
name: Admin mobile layout
description: Tournament settings on mobile retain the compact desktop-style admin layout with a narrow icon sidebar
type: design
---
Op mobiele schermen blijft de toernooibeheeromgeving zoals in de aangeleverde referenties: een vaste compacte zijbalk met iconen en labels, een compacte bovenbalk, en de instellingen rechts daarvan. De beheerpagina mag niet omschakelen naar een mobiele onderbalk of hamburger-menu. Bij toekomstige aanpassingen aan instellingen moet deze mobiele weergave altijd behouden en gecontroleerd worden.
