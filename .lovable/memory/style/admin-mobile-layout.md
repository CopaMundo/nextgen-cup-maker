---
name: Admin mobile layout
description: Tournament admin on mobile uses a full-height, collapsible app sidebar with an always-visible compact state
type: design
---
Op mobiele schermen gebruikt de toernooibeheeromgeving een echte mobiele app-indeling en nooit een verkleinde desktopweergave. Een smalle iconenbalk blijft over de volledige beschikbare hoogte zichtbaar. Uitklappen opent een compacte laag over de inhoud, zodat de werkruimte niet smaller wordt; na een keuze klapt de balk weer in. De instellingen blijven overzichtelijk rechts van de iconenbalk.

**Regel:** Geen mobiele onderbalk of volledig verdwijnend hamburger-menu. Bij toekomstige aanpassingen aan instellingen of beheerpagina's moet de full-height inklapbare zijbalk behouden blijven en altijd in mobiele weergave (393px) gecontroleerd worden.
